# xssi 1.0.0

独立安装维护工具提供首次安装、只读检查、管理员密码重置、媒体配置重建，以及调用 XSSC 的升级入口。服务端运行程序只加载已有安装状态；安装不自动启动或启用服务。

Linux x86_64 GNU 工具包包含入口脚本、受控 Python 模块、独立 `libexec/setup`、操作说明及原始许可证。它不包含任何用户配置、数据库、凭据或业务数据。安装目标使用对应 Server 发行包中的当前契约材料，不依赖相邻产品源码。

正式构建从对应标签的清洁源码导出，生成实际目标的运行依赖图、SQLite 来源及许可、最终文件与原生依赖物料清单，再建立完整 SHA256 清单。归档重新解包后验证全部文件、发行身份和实际辅助程序版本。发行不使用自定义签名或发行私钥。

安装日志、启动控制记录、创建授权及发行清单均使用当前 v1 格式；安装与升级工具的软件版本为 1.0.0。工具只读取当前格式，不提供旧格式兼容或转换。

实际运行依赖 `borrow-or-share 0.2.4` 的原始许可证已与 [SPDX MIT No Attribution 定义](https://spdx.org/licenses/MIT-0.html) 核对，`MIT-0` 纳入审核集合，发行包保留实际许可证原文。

依赖清单使用实际包、目标和特性选中的 Cargo 普通依赖树，排除其他工作区成员启用的依赖与过程宏。最终二进制、动态依赖和文件清单另行核验。

许可审核将原始 Cargo 声明与固定成熟工具生成的实际组件 SPDX 表达式逐一绑定，保留原声明和完整原文。已核对的历史斜杠声明须与成熟解析语义一致；未知表达式和未经审核的许可继续拒绝。原文支持物理 `LICENSES` 目录，以及当前确需使用的依赖在精确上游源码中的原许可记录，不使用其他项目的通用文字替代。

安装权限验证在最终 systemd 沙箱内实际检查无符号链接的 `openat2` 路径访问、服务身份、禁止提升权限与空能力集。系统不支持必要调用时安装失败；服务模板保留严格文件系统保护，并避免会阻止此必要调用的 `RestrictSUIDSGID` 设置。

Windows 发行文件读取区分路径和文件句柄的时间戳语义，同时保留读取前后身份及元数据一致性检查，拒绝读取期间同大小且恢复修改时间的内容改写。

实际发行结果以正式工作流和资产核验为准；Linux 测试不代替 Windows 原生安装器或实际产品部署验收。
