# xssi 1.0.1

修复首次安装后尚未启动的 systemd 单元被回收时，安装器无法检查启动条件的问题。使用 systemd 的 LoadUnit 只加载单元定义，仍严格核验启动条件、属性和配置，不启动或启用服务。

修复多入口前端构建中导入、再导出的入口文件缺少来源记录的问题，绑定到实际在共享代码块中编译的同一源码模块；没有真实编译来源的入口仍被拒绝。

Windows 发行校验准确识别系统 ncrypt 库，并逐项核对当前 MSI 的原始注册表查询，拒绝新增文件查询或未审查的安装行为。

软件版本为 1.0.1；自有配置、清单、数据库和协议仍为 v1。发行包包含完整 SHA-256 清单和实际依赖来源、原始许可证。
