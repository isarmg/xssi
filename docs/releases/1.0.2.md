# xssi 1.0.2

修复 Android 运行时依赖的原始 Maven POM 包含合法空属性时，许可证清单生成被错误拒绝的问题。保留标量空值参与实际字段解析；重复属性、嵌套属性、空的依赖坐标或许可证名称和来源仍被拒绝。

修复首次安装在写入所选配置前校验管理员凭据，导致辅助程序读取未准备的默认配置并错误拒绝安装的问题。凭据校验现在明确使用已记录的所选配置；无效配置、弱密码和已有未知状态仍被拒绝。

修复 XCZS 的业务共享目录被错误要求同时属于私有状态备份路径的问题。共享目录仍须同时声明为实际业务目录和可写目录，并保留与私有状态、配置和工具控制区不得重叠的边界；不更改已有共享文件的内容、权限或属主。

修复 MediaMTX 服务模板对 `EnvironmentFile` 整个路径添加引号，导致 systemd 将它当作非绝对路径并忽略的问题。保留执行参数引用与现有服务保护，使用实际 systemd 解析验证正常和含空格的安装根。

修复前端库存拒绝 DOMPurify 的原始双许可声明，以及漏识别 punycode.js 的标准 `LICENSE-MIT.txt` 文件名的问题。保留精确上游双许可声明及两份对应原文，并核对本地元数据与原始 npm 包身份；未知许可、缺失或空原文仍被拒绝。

继续严格核对实际运行时文件与上游原始字节、SHA-256、POM 身份、许可证及原始声明，不采用替代许可证或放宽来源校验。

安装脚本和服务模板也随各 Server 发行包交付；单独更新 XSSI 不能改变此前已发布包的内容。受影响 Server 需绑定修复后的工具来源重新发布，既有发行标识的内容不覆盖。

软件版本为 1.0.2；自有配置、清单、数据库和协议仍为 v1。发行包包含完整 SHA-256 清单和实际依赖来源、原始许可证。
